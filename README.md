# Photography Portfolio

A modern, responsive photography portfolio website built with HTML, CSS, and JavaScript.

This project demonstrates the design and development of a professional photography website focused on showcasing visual content through elegant layouts, responsive galleries, and an intuitive user experience. Multiple development versions were created to refine the interface, improve usability, and experiment with different design concepts.

## Features

- 📷 Professional photography portfolio
- 🖼️ Responsive image gallery
- 🎨 Modern and minimal design
- 📱 Mobile-friendly layouts
- ⚡ Lightweight and fast-loading pages
- 🖥️ Responsive navigation
- ✨ Interactive user interface
- 🧩 Multiple development iterations

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/endritngjelina/Photography.git
```

### Run locally

Open the latest HTML file directly in your browser, or run a local development server.

Using Python:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```

Or use the **Live Server** extension in Visual Studio Code.
